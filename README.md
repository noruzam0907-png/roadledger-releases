# 운행노트

Android 운행 기록·콜 등록·동선 계산·지도 메모 앱의 공식 배포 저장소입니다. APK와 업데이트 안내만 제공합니다.

[최신 버전 다운로드](https://github.com/noruzam0907-png/roadledger-releases/releases/latest) · [개인정보처리방침](https://roadledger-map-gateway.noru0907.workers.dev/privacy)

## 설치

Android 8.0 이상에서 릴리스에 첨부된 `roadledger-public-*.apk`를 받아 설치하세요. 개인용 운행노트와 별도로 설치되며 기존 개인용 기록은 자동으로 옮겨지지 않습니다.

배포판에는 카카오 픽커 자동수락 기능이 없습니다. 광고는 운행노트 화면 하단에 표시되며 광고 제공 상황에 따라 표시되지 않을 수 있습니다.

## 업데이트

앱 설정의 **업데이트 확인**으로 새 버전을 확인할 수 있습니다. 최초에는 Android에서 운행노트의 앱 설치 허용과 설치 확인이 필요할 수 있습니다.

Android 12 이상은 **업데이트 자동 설치**를 켜면 앱을 열고 운행 중이 아닐 때 자동 업데이트를 시도합니다. Android가 확인을 요청하면 설치를 눌러주세요. 업데이트는 같은 앱에 덮어쓰며 운행 기록·메모를 유지합니다. 앱을 삭제하거나 데이터를 지우지 마세요.
